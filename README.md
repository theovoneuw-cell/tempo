# Tempo

Tap tempo et recherche de gamme pour iPhone, hors ligne.

- **Tempo** : tape en rythme n'importe où, le BPM s'affiche (moyenne par moindres carrés sur les 32 dernières frappes).
- **Gamme** : touche pour écouter une note, reste appuyé pour la garder. L'app déduit la gamme et son équivalent majeur/mineur. Avec 7 notes, « Solo » improvise une mélodie dans la gamme au tempo choisi.

Installation : ouvrir https://theovoneuw-cell.github.io/tempo/ dans Safari, puis Partager → Sur l'écran d'accueil.

⚠ Incrémenter `CACHE` dans `sw.js` à chaque modification.
